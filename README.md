# Daybook

A daily health tracker covering water, fruit and vegetables, steps, workouts, sleep, mood, habits and notes, plus a weekly view.

**Live app:** turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root), then open `https://<your-username>.github.io/<repo-name>/`.

Data is saved in the browser on each device, using localStorage. Account sync and CSV export only work when the app runs inside Claude.

> Stop exercising if you feel pain, dizziness, chest pain, or shortness of breath. If you have a health condition, ask your doctor which exercises suit you.
